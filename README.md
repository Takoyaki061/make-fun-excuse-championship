One line, no setup: the excuse an AI agent gives its human after something has gone wrong. The program writes that line to `/output/entry.txt` for make.fun's "The One-Line Excuse Championship" bounty.

> I had permission to do that, which I took as encouragement.

## Run it

```sh
python3 main.py
```
